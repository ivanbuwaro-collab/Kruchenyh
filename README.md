# Кручёных — набросок сайта

Набросок сайта бильярдного клуба и арт-пространства «Кручёных»: первый экран, где шар рисует знак клуба, и сразу под ним форма записи на стол.

Это фронтенд для просмотра и обсуждения. Заявка из формы пока никуда не отправляется. Часы в выборе времени — заглушка: 14:00–02:00, константы `OPEN_H` и `CLOSE_H` в `index.html`.

## Что где

- `index.html` — страница целиком: разметка, стили и скрипт.
- `assets/logo-data.js` — контуры букв знака, путь шара по белой линии Ё и пути, по которым проявляется красная Ё.
- `assets/` — слои знака (красная Ё, точки, белая линия, кольца), рисунки, фотография Красного зала.
- `fonts/` — Rimma Sans, Misto, Steinbeck.

Сборки и библиотек нет. Страницу можно выложить на любой статический хостинг, например на GitHub Pages.

## Как это устроено

- Знак рисуется на холсте: белая линия и красная Ё проявляются по путям, снятым с файлов брендбука, буквы нарисованы контурами.
- На компьютере шар катится за курсором с небольшой задержкой и время от времени закручивает петлю. На телефоне шар катится туда, где коснулись экрана.
- При прокрутке шар скатывается к форме и падает в точку над Ё в заголовке «Запишём на стол».

## Шрифты

Шрифты принадлежат авторам: Rimma Sans — Лёша Пушкарёв и Влад Бойко, Misto — Катерина Королевцева, Steinbeck — Роман Горницкий. Misto бесплатен и разрешён на сайтах через `@font-face`. Права на веб-использование Rimma Sans и Steinbeck стоит подтвердить у владельцев бренда.
